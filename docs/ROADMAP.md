- [ ] **T303 動力學失配穩健度（sim-to-sim）**：連桿質量／慣性 ±20%、摩擦 0.3–1.2、伺服頻寬、延遲掃描，比較腳本控制與 RL（有／無 DR）的成功率曲線，找出各方法的失效邊界。相依：T207
- [ ] **T304 高階任務指令**：以 T007 JSON/DSL 擴充高階指令（例如「把紅色物件放到料箱 A，然後幫 CNC 上料 3 件」），由主動判斷層拆解為技能序列；測試指令解析正確率與執行成功率。相依：T208d
- [ ] **T305 長時程工作站示範**：模擬 30 分鐘班次（輸送帶來料 → 分類 → 上下料 → 碼垛），隨機注入故障；KPI：產出數、平均週期、可用率、故障次數與自動恢復率、需人工介入次數。相依：T301、T304
- [ ] **T306 人機協作安全**：依 ISO/TS 15066 速度與分離監控（SSM）概念，以移動障礙物代表人員進入工作區，實作分區降速／停止，量測最小分離距離與產能損失。相依：T110、T305
